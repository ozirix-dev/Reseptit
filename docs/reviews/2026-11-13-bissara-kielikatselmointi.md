# Bissaran kielikatselmointi

FI, EN, SV ja TH tarkistettu rinnakkain. Ainesmäärät, kuorittu halkaistu papu, erillinen kylmä liotusvesi, kypsennys, annoskoko, G6PD-huomautus ja kuvan tarjoiluehdotus täsmäävät. Kokonaisajan arvio on 555 minuuttia liotus mukaan lukien. Kaikki ravintolaskennan lähtöarvot säilyvät. Valmistettavuutta arvioitiin vertailuohjeista.
