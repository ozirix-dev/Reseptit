# Recipavon ensimmäinen uusi kielierä

Kahdeksan aiemmin FI-kielellä julkaistua lähdettä verrattiin uusiin EN-, SV- ja TH-versioihin. Ainesrivit, määrät, annokset, menetelmät, kypsyys, allergeenit, säilytys, kuvan tunniste sekä lähdeviitteet tarkistettiin. Thain kuumennus- ja käsittelyohjeet tarkistettiin takaisin FI-merkitykseen.

Julkaistujen FI-versioiden ravintotieto- ja GK-tilat kopioituvat nykyisen sisällöntuotannon kautta. Uusia ravintoarvoja tai GK-lukuja ei päätelty. Hyväksyntä on Codexin dokumentoitu lähdevertailu.

| Resepti | Tarkistuksessa painotettu |
| --- | --- |
| Kaali-omenasalaatti | Valmiin kastikkeen vaihtelevat allergeenit, kylmäsäilytys. |
| Uunibataatit fetalla | Paino kuorineen, uunin lämpö, kypsyys haarukalla, maito ja seesami. |
| Uuniriisipuuro | Täysmaito, riisilaatu, 175 °C, nopea jäähdytys. |
| Kookos-linssikeitto | Kuivat punaiset linssit, kypsäksi keittäminen, kuuman keiton soseutus. |
| Porkkanaletut | Kaksi margariinimäärää ja letun kypsyys keskeltä. |
| Papu-myskikurpitsapelti | Kypsät säilykepavut, soija ja pekaanipähkinät. |
| Mustaherukkavispipuuro | Tuontimarjojen vähintään kahden minuutin kiehautus, vehnä ja jäähdytys ennen vatkausta. |
| Rasvakaakao | Sama 90 % suklaatuote, nestemäinen 35 % kerma, maito ja pakkausmerkinnät. |
