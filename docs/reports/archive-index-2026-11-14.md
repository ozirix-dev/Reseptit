## Paikallisten työpuiden erillinen siivous

GitHubissa tehtävä PR **ei voi poistaa käyttäjän Windows-koneella sijaitsevia
Git-työpuita**. Aiemmin raportoitu 390 työpuuta ja 264 mainiin sisältyvää
HEAD-committia ovat paikallista tilannekuvaa, eivät tämän PR:n tuloksia.
Commithistoriaan sisältyminen ei yksin tarkoita, että työpuu olisi poistettavissa.

Paikallisessa siivouksessa tarkista `git worktree list --porcelain`,
jokaisen ehdokkaan `git -C <tyopuu> status --porcelain`,
`git merge-base --is-ancestor <HEAD> main`, avoimiin PR:iin liittyvät
branchit ja käynnissä olevien ajojen aktiivisuus. Poista vain puhdas,
käyttämätön, ei-PR-työpuu komennolla `git worktree remove <polku>`.
Älä käytä massapoistossa `--force`; tavallinen `git worktree prune`
ei poista hyvinvoivia rekisteröityjä työpuita.
