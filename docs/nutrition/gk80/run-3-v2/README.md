annostarkistuksilla. Julkaistu imputointi säilyy eri asiana kuin mitattu GI. Pienen mausteannoksen
GI 50 -laajennus ja enintään 5 g/100 g -tulkinta tarvitsevat nimenomaisen menetelmähyväksynnän.

## Toistaminen

```powershell
python site/scripts/gk80-run3-verify.py
cd site
npm run test:gk80
```

Python Decimal käyttää 40 numeron tarkkuutta ja aiemman Python-verifioijan puhtaita laskentafunktioita.
TypeScript-toteutus ei tuo Pythonin algoritmia. Jokainen ainesosatermi ja neljä makroa verrataan.
Lähde-, koostumus- ja reseptihashit tarkistetaan; hash ei todista tieteellistä soveltuvuutta.
Lopulliset testit, PR:t ja CI ovat ajon handoffissa ja GitHubin täsmällisellä HEADilla.
