1. Esikeitetyn perunan versio: keitä 600 g punnittua kuorittua raakaa perunaa 1000 g:ssa vettä kypsäksi ja valuta. Raakaperunan makroista ei vähennetä mittaamatonta liukenemishävikkiä.
