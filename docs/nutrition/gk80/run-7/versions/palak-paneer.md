## Valmistus

1. Punnitse luetellut syötävät raaka-aineet grammoina; älä lisää luetteloimatonta rasvaa tai lisukkeita.
2. Sekoita kuusi garam masalan maustetta (yhteensä2g). Punnitse250g paneeria, jonka koostumuksena käytetään nimettyä norjalaista paneer-proxya.
3. Ruskista paneer puolessa öljystä ja siirrä sivuun. Kuullota sipuli lopussa öljyssä. Lisää valkosipuli, inkivääri, juustokumina ja kurkuma.
4. Lisää pinaatti ja50g vettä suoraan pannulle. Hauduta pinaatti pehmeäksi, soseuta karkeasti ja säilytä kaikki neste; tässä versiossa ei ryöpätä eikä valuteta.
5. Lisää kerma, garam masala ja paneer. Kuumenna5min ja lisää sitruunamehu. Jaa koko seos neljään annokseen.
6. Kypsennä kaikki raakaa eläinperäistä ainesta sisältävät osat kypsiksi. Syö kaikki tämän punnitun version ainekset ja kastike/pannuneste. Raakojen ainesten ravintokoostumus on kypsän ruoan proxy; mittaamatonta hävikkiä ei vähennetä.
