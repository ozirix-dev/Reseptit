## Valmistus

1. Punnitse luetellut syötävät raaka-aineet grammoina; älä lisää luetteloimatonta rasvaa tai lisukkeita.
2. Valmista5g nimettyä tuoreharissaa hienontamalla chili2.5g,valkosipuli0.8g,öljy1g,juustokumina0.3g,korianteri0.2g,sitruunamehu0.2g. Käytä koko tahna.
3. Kuullota paprika ja tomaatti13.5g öljyssä. Lisää tuoreharissa ja hauduta pehmeäksi.
4. Lisää110g kuoretonta kananmunaa, peitä ja kypsennä kauttaaltaan. Jaa kaikki kasvikset,kastike ja munat kahteen annokseen.
5. Kypsennä kaikki raakaa eläinperäistä ainesta sisältävät osat kypsiksi. Syö kaikki tämän punnitun version ainekset ja kastike/pannuneste. Raakojen ainesten ravintokoostumus on kypsän ruoan proxy; mittaamatonta hävikkiä ei vähennetä.
