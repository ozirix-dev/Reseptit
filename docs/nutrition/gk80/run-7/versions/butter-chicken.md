## Valmistus

1. Punnitse luetellut syötävät raaka-aineet grammoina; älä lisää luetteloimatonta rasvaa tai lisukkeita.
2. Sekoita kuusi garam masalan maustetta (yhteensä4g), juustokumina2g, jogurtti ja sitruunamehu. Marinoi700g syötävää nahatonta reisilihaa20min.
3. Ruskista broileri öljyssä; säilytä kaikki marinadi. Kuullota sipuli voissa, lisää valkosipuli, inkivääri ja paprika. Lisää tomaattimurska, hauduta10min.
4. Lisää kerma, hunaja21g, broileri ja koko marinadi. Kypsennä broileri kauttaaltaan kypsäksi. Viimeistele korianterilla ja jaa kaikki kastike sekä liha neljään annokseen. Lisukkeet eivät kuulu tähän versioon.
5. Kypsennä kaikki raakaa eläinperäistä ainesta sisältävät osat kypsiksi. Syö kaikki tämän punnitun version ainekset ja kastike/pannuneste. Raakojen ainesten ravintokoostumus on kypsän ruoan proxy; mittaamatonta hävikkiä ei vähennetä.
