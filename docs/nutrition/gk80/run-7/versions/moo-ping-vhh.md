## Valmistus

1. Punnitse luetellut syötävät raaka-aineet grammoina; älä lisää luetteloimatonta rasvaa tai lisukkeita.
2. Sekoita kookosmaito,kalakastikeproxy,soijakastike,valkosipuli,korianterinvarret,mustapippuri ja erytritoli. Marinoi porsas30min. Mustapippuri on tämän version nimenomainen valinta.
3. Paista öljyssä pannulla; lisää koko marinadi pannulle ja kypsennä liha sekä raakaan lihaan koskenut marinadi kauttaaltaan. Tässä pannuversiossa mitään marinadia ei valuteta pois eikä grillihävikkiä arvioida.
4. Tarjoa200g kurkkua ja60g kuorittua limetin hedelmälihaa/mehua; käytä kaikki luetellut syötävät osat. Jaa neljään annokseen.
5. Kypsennä kaikki raakaa eläinperäistä ainesta sisältävät osat kypsiksi. Syö kaikki tämän punnitun version ainekset ja kastike/pannuneste. Raakojen ainesten ravintokoostumus on kypsän ruoan proxy; mittaamatonta hävikkiä ei vähennetä.
