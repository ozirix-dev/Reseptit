## Valmistus

1. Punnitse luetellut syötävät raaka-aineet grammoina; älä lisää luetteloimatonta rasvaa tai lisukkeita.
2. Tämä on alkuperäisen valinnaisen siirapin pois jättävä makeuttamaton versio. Punnitse800g kuorittua lanttua ja kypsennä peitettynä100g vedessä pehmeäksi; säilytä kaikki neste soseessa. Lisää tarvittaessa vettä vain haihtuneen korvaamiseksi, älä valuta lanttua.
3. Soseuta. Käytä osa50g voista vuokaan ja pinnalle,loput seokseen. Lisää kerma,muna,muskotti ja mustapippuri. Kokonaisvoimäärä on50g; ylimääräistä rasvaa ei lisätä.
4. Paista175°C:ssa noin60min kauttaaltaan kypsäksi. Anna vetäytyä10min ja jaa koko vuoka neljään annokseen.
5. Kypsennä kaikki raakaa eläinperäistä ainesta sisältävät osat kypsiksi. Syö kaikki tämän punnitun version ainekset ja kastike/pannuneste. Raakojen ainesten ravintokoostumus on kypsän ruoan proxy; mittaamatonta hävikkiä ei vähennetä.
