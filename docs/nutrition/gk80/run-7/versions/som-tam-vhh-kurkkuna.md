## Valmistus

1. Punnitse luetellut syötävät raaka-aineet grammoina; älä lisää luetteloimatonta rasvaa tai lisukkeita.
2. Kaavi kurkun siemenosa pois ja punnitse sen jälkeen500g syötävää kurkkua. Punnitse100g jo keitettyjä ja valutettuja vihreitä papuja; raakoja papuja ei käytetä sellaisenaan. Paloittele tomaatti.
3. Murskaa valkosipuli, chili ja puolet kokonaisista paahdetuista maapähkinöistä. Lisää limettimehu, nimetty kalakastikeproxy ja4g Foodin-erytritolia.
4. Sekoita kaikki kasvikset ja kastike. Lisää loput maapähkinät. Syö koko kastike ja jaa neljään annokseen.
5. Kypsennä kaikki raakaa eläinperäistä ainesta sisältävät osat kypsiksi. Syö kaikki tämän punnitun version ainekset ja kastike/pannuneste. Raakojen ainesten ravintokoostumus on kypsän ruoan proxy; mittaamatonta hävikkiä ei vähennetä.
