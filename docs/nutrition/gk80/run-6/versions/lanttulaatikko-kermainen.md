## Valmistus ja version rajaus

Punnitse luetellut syötävät raaka-aineet grammoina; älä lisää luetteloimatonta rasvaa tai lisukkeita.

Tämä on alkuperäisen valinnaisen siirapin pois jättävä makeuttamaton versio. Punnitse800g kuorittua lanttua ja kypsennä peitettynä100g vedessä pehmeäksi; säilytä kaikki neste soseessa. Lisää tarvittaessa vettä vain haihtuneen korvaamiseksi, älä valuta lanttua.
