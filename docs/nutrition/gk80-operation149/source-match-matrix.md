# Jatkoehdotusten lähdevastaavuuden päätösmatriisi

**Kuuden A-version erillinen hyväksyntä on nyt kirjattu approved-six-owner-approval.json:iin.22 tarkkaa versiota on integroitu Draftiin,178/326; tuotanto156.** Alkuperäisen14 ehdotuksen alla oleva lähdearvio säilyy. Kahvijogurtin valittu A-versio, pad kee mao ja Chettinad on hyväksytty; hojichasta hyväksyttiin erillinen täyslehtinen A-versio. Natto ja dashimaki lisättiin samassa päätöksessä. Haudukevaihtoehto ja muut versiot eivät peri hyväksyntää. Kuusi valmistetun ruoan/komponentin tapausta pysyy lähde-HOLDissa. Omistajan päätös ei korvaa puuttuvaa lähdenäyttöä.

Matriisin rivit ovat versioehdotuksia, eivät uniikki kattavuuslaskuri. Yhteisessä33 reseptin koonnissa11 reseptiltä puuttuu hyväksytty versio: kuusi lähde-HOLDia ja viisi muuta avointa tapausta.
