# GK-erä 8 — 25.10.2026

Erässä käytiin läpi 20 aiemmin käsittelemätöntä reseptiä: 11:lle oli jo ainesosakohtainen ravintoarvolaskelma ja yhdeksän tarkistettiin rakenteisesta reseptisisällöstä. Laskenta käytti Fineli Rel20:n ja AFCD Release 3:n imeytyviä hiilihydraatteja reseptin annosmäärää kohti. GI-arvona käytettiin lähteistettyä riisin, palkokasvien, vihannesten, leipien, viljatuotteiden, maitotuotteiden, pähkinöiden, sokerien ja keittojen luokkakeskiarvoa aina kun se sopi ruoka-aineeseen riittävän hyvin. Nämä ovat matalan luottamuksen ainesosalaskelmia, eivät valmiin aterian mittauksia.

## Lähteet ja tulkinta

Hiilihydraatit: THL:n Fineli Food Composition Database Release 20 (CC BY 4.0) sekä vain Finelin puuttuessa FSANZ:n AFCD Release 3 (CC BY-SA 3.0 Australia). GI-luokkakeskiarvot on laskettu *International Tables of Glycemic Index and Glycemic Load Values 2021* -julkaisun ISO-menetelmää vastaavasta Supplemental Table 1 -aineistosta. Luokkakeskiarvo ei ole yksittäisen reseptin ainesosan mitattu GI, joten julkiset arvot on merkitty ohjeellisiksi arvioiksi. Ks. [Fineli](https://fineli.fi/fineli/fi/avoin-data), [International Tables 2021](https://doi.org/10.1093/ajcn/nqab233) ja [AFCD](https://www.foodstandards.gov.au/science-data/monitoringnutrition/afcd).

Syötteet, tietuekohtaiset lähteet, muunnokset ja epävarmuudet ovat `glycemic-load-pilot-input.json`-tiedostossa ja generoitu sisäinen eräraportti `tmp/nutrition/glycemic-load-pilot.json`-polussa.
