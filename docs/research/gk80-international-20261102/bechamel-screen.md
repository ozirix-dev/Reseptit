# GK80 · béchamelin tuotereitin raja

Main `1276116d8bd4c84fc62ededebc8304a73c1cc9e1`. Reseptihakemistosta löytyi kaksi béchamel- tai valkokastikemainintaa. `kreikkalainen-moussaka` käyttää kastiketta. `munakoiso-kesakurpitsalasagne` kertoo erikseen, että se käyttää tomaattikastiketta. Lasagne on myös Codex2:n prioriteettijonossa. Tämän haun perusteella béchamelin ratkaisu voisi avata enintään yhden nykyreseptin.

Alkuperäisen moussakan 60 g vehnäjauhoa tuo 7,3998 g saatavaa hiilihydraattia annokseen. Se on ratkaiseva este, vaikka muille ainesosille löydettäisiin sopivat GI-sidonnat. Jauhoa ei jätetä pois.

| Nimetty kastike | Valmistajan hiilihydraatti | Vertailumäärä, jolla kastike yksin saavuttaa 1 g/annos kuudelle |
| --- | ---: | ---: |
| Massel, valmistettu béchamel | 5,86 g/100 ml | 102,39 ml |
| Lukull, valmis béchamel | 10 g/100 ml | 60 ml |
| Granarolo, béchamel | 10,5 g/100 ml | 57,14 ml |

Määrät ovat laskennallisia rajapisteitä, eivät reseptiehdotuksia. Sääntö vaatii alittamaan ne. Jo pelkän alkuperäisen maitomäärän suuruinen 600 ml vertailuerä tuottaisi 5,86–10,5 g hiilihydraattia annosta kohti näillä tuotteilla. 600 ml ei ole väite kotitekoisen kastikkeen saannosta. Käyttämällä koko kastikkeen tuotetietoa sen hiilihydraattia ei voi pilkkoa erillisiin sokeri- ja tärkkelysriveihin ilman dokumentoitua koostumussidontaa. **Vaikutus 0 uutta ehdokasta.** Näillä tuotteilla etikettireitti ei ratkaise kokonaisen kastikeannoksen GI:tä. Moussakan [aiempi valmisruokavertailu](moussaka-study.md) säilyy ehdollisena. Seuraava vaikuttava lähde olisi valmistustavaltaan vastaavan roux-kastikkeen ihmis-GI tai koko naudanlihamoussakan mittaus. Aiemman selvityksen perusteella tuotekoostumushaun laajentaminen muihin nykyisiin resepteihin ei avaa toista tapausta.
