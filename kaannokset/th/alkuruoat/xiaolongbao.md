# เสี่ยวหลงเปา เกี๊ยวน้ำแบบจีน

เกี๊ยวน้ำทำเองสอดไส้หมูและเจลลี่น้ำสต๊อกที่ละลายเป็นน้ำซุปเมื่อนึ่ง

## Description

เกี๊ยวน้ำทำเองสอดไส้หมูและเจลลี่น้ำสต๊อกที่ละลายเป็นน้ำซุปเมื่อนึ่ง

## Preparation

1. ละลายเจลาตินในน้ำสต๊อกแล้วแช่เย็นอย่างน้อย 30 นาทีจนเซ็ตตัว จากนั้นหั่นเป็นชิ้นเล็ก

2. ผสมหมูบด ต้นหอม ซีอิ๊ว น้ำมันงา ขิง และเกลือ ค่อย ๆ คลุกเจลลี่น้ำสต๊อกลงไป

3. แบ่งแป้งเป็น 24 ส่วน รีดบาง ใส่ไส้เล็กน้อย พับจีบและบีบปิด

4. วางเกี๊ยวบนกระดาษรองอบหรือใบกะหล่ำในลังถึง อย่าให้ติดกัน

5. นึ่งเหนือน้ำเดือด 8–10 นาทีจนไส้สุก

6. เสิร์ฟทันทีพร้อมน้ำส้มสายชูข้าวดำและขิง ระวังน้ำซุปร้อนด้านใน

## Notes

- รักษาไส้ให้เย็นระหว่างห่อเกี๊ยว
