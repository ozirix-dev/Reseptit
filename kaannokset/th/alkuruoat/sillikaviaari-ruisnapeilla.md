# สเปรดปลาเฮร์ริงแบบฟินแลนด์บนแครกเกอร์ไรย์

ฉบับแปลร่างเพื่อให้บรรณาธิการตรวจทาน ยังไม่มีการทดสอบปรุงจริงโดย Recipavo

## วิธีทำ

1. ต้มไข่ให้สุกแข็งประมาณ 9–10 นาทีแล้วทำให้เย็นอย่างรวดเร็ว
2. สะเด็ดน้ำปลาเฮร์ริงพร้อมรับประทานแล้วสับละเอียด สับหอมหัวใหญ่สีแดง ไข่ และผักชีลาว
3. ผสมส่วนผสมที่สับกับสเมทานา ครีมเฟรช และน้ำเลมอน ชิมรสเค็ม
4. แช่สเปรดในตู้เย็น ตักวางบนแครกเกอร์ไรย์ก่อนเสิร์ฟเพื่อให้แครกเกอร์กรอบ

## ข้อควรระวังด้านความปลอดภัย

ใช้เฉพาะปลาเฮร์ริงพร้อมรับประทานและเก็บเย็น มีสารก่อภูมิแพ้จากปลา ไข่ นม และไรย์ แม้ชื่ออาหารดั้งเดิมหมายถึงคาเวียร์ แต่สูตรนี้ไม่มีไข่ปลา

## บันทึกบรรณาธิการ

- สูตรภาษาฟินแลนด์เป็นต้นฉบับหลัก ฉบับแปลนี้ยังไม่ได้รับอนุมัติให้เผยแพร่
- ต้องตรวจความถูกต้องของปริมาณ วิธีทำ ความปลอดภัย และความเทียบเท่าของความหมาย
- ยังไม่ได้คำนวณสารอาหารหรือค่าภาระน้ำตาล
- ภาพ WebP ขนาด 720 × 720 พิกเซลอยู่ในการควบคุมเวอร์ชัน Git และมีค่า SHA-256 ในรายการภาพ ภาพนี้สร้างด้วย AI ไม่ใช่ภาพถ่ายอาหารที่ปรุงจริง ฉบับแปลยังเป็นร่างและยังไม่ได้รับอนุมัติให้เผยแพร่
