# แพตตีเนื้อบดกับซอสครีมไม่ใส่แป้ง

เนื้อบดเนื้อฉ่ำและซอสครีมปรุงในกระทะนำการปรุงอาหารที่บ้านที่คุณคุ้นเคยมาเสิร์ฟบนโต๊ะโดยไม่ต้องใช้เกล็ดขนมปังหรือแป้งสาลี

## คำอธิบาย

สเต็กมีโครงสร้างมาจากไข่และเนื้อสับ ซอสจะข้นช้าๆ โดยการต้ม และสามารถเสิร์ฟพร้อมดอกกะหล่ำบดหรือผักใบเขียวได้

## วิธีทำ

1. ผสมเนื้อสับ ไข่ ครีม หัวหอมขูด เกลือ และพริกไทยดำลงในชาม ปั้นเป็นสี่ชิ้น
2. ตั้งเนยในกระทะ ทอดเนื้อบดที่ปั้นไว้ด้วยไฟปานกลางด้านละประมาณ 4–5 นาทีจนสุกทั่ว แล้วตักพักไว้
3. เทน้ำซุปเนื้อลงกระทะแล้วใช้ตะหลิวขูดส่วนที่เกรียมติดก้นกระทะให้ละลายเข้ากับน้ำซุป ใส่ครีม มัสตาร์ด และพริกไทย
4. เคี่ยวซอส 5–8 นาทีจนข้นเล็กน้อย ใส่เนื้อบดทอดกลับลงไปแล้วอุ่นต่ออีกสักสองนาที
5. เสิร์ฟพร้อมดอกกะหล่ำบดหรือผักใบเขียว

## หมายเหตุ

- ถ้าน้ำซุปมีรสเค็มให้ชิมน้ำซอสก่อนเติมเกลือเพิ่มเติม

ค่า GK และโภชนาการใช้กับส่วนผสมส่วนที่กินได้ซึ่งชั่งตามรายการนี้และจำนวนที่เสิร์ฟนี้เท่านั้น GK เป็นค่าประมาณจากแบบจำลองที่มีความเชื่อมั่นต่ำ รหัส GI ที่ใช้ไม่ใช่ผลการวัดอาหารจานนี้ การไม่นับส่วนผสมปริมาณน้อยที่มีหลักฐานกำกับเพิ่มความไม่แน่นอน เครื่องเคียงที่แนะนำไม่รวมในการคำนวณ หากเปลี่ยนผลิตภัณฑ์หรือปริมาณต้องประเมินใหม่
