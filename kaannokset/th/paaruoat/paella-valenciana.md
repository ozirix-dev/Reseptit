# ปาเอญ่าบาเลนเซียไก่

ไก่และข้าวเมล็ดสั้นหุงพร้อมถั่วแขกในน้ำสต๊อกหญ้าฝรั่น

## Description

ไก่และข้าวเมล็ดสั้นหุงพร้อมถั่วแขกในน้ำสต๊อกหญ้าฝรั่น

## Preparation

1. ตั้งน้ำมันในกระทะกว้างและจี่ไก่ให้เหลืองทั่ว

2. ใส่ถั่วแขก ผัดสักครู่ แล้วใส่มะเขือเทศและปาปริก้ารมควัน

3. ใส่ข้าวดิบและน้ำสต๊อกร้อนที่แช่หญ้าฝรั่น ปรุงเกลือและใส่กิ่งโรสแมรี่

4. ปรุงด้วยไฟกลาง 8 นาที แล้วลดไฟอ่อนอีก 12–15 นาที อย่าคนหลังเติมน้ำสต๊อก

5. ยกลงเมื่อข้าวนุ่มและน้ำแห้ง ปิดฝาพัก 5 นาที แล้วนำโรสแมรี่ออกก่อนเสิร์ฟ

## Notes

- สูตรนี้ใช้เนื้อสะโพกไก่ไม่มีกระดูกเท่านั้น
