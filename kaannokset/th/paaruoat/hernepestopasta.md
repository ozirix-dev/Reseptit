# พาสต้าซอสเพสโตถั่วลันเตา

โหระพาอิตาเลียน เม็ดมะม่วงหิมพานต์ และเลมอนปรุงรสซอสถั่วลันเตาปั่น ส่วนถั่วอีกครึ่งหนึ่งใส่ลงในพาสต้าทั้งเม็ด

## วิธีทำ

1. ต้มพาสต้าตามคำแนะนำบนบรรจุภัณฑ์ ตักน้ำต้มเส้นเก็บไว้เล็กน้อยก่อนสะเด็ดน้ำ
2. ต้มถั่วลันเตาแช่แข็งในน้ำเดือดตามคำแนะนำบนบรรจุภัณฑ์แล้วสะเด็ดน้ำ ปอกและสับกระเทียมกับหอมแดง
3. ปั่นถั่วครึ่งหนึ่งกับกระเทียม หอมแดง เม็ดมะม่วงหิมพานต์ โหระพาอิตาเลียน น้ำเลมอน เกลือ และน้ำมันคาโนลา ผสมแครมแฟรชลงไป ถ้าซอสข้นเกินไปให้เติมน้ำต้มพาสต้าเล็กน้อย
4. คลุกพาสต้าที่สะเด็ดน้ำแล้วกับซอสเพสโตและถั่วลันเตาต้มที่เหลือ เสิร์ฟทันที
